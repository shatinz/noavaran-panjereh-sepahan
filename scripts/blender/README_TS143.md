# TS143 Blender source

Regenerate the scene and web exports with the portable Blender version used for this asset:

PowerShell command:
C:\Temp\blender-5.2.3-windows-x64\blender.exe --background --python .\scripts\blender\build_ts143_scene.py

The generator writes:
- assets/source/ts143.blend — editable Blender source
- public/models/ts143.glb — compact glTF binary
- public/models/ts143_scene.json — per-part vertex/index geometry, bilingual labels, provenance, stage and interaction metadata

This is a catalogue- and animation-informed educational/marketing visualization. It is not a production cut list or certified fabrication/installation model. Confirm real fitting profiles, glass recipe, dimensions and adjustments with AKPAi and the selected fitting supplier before manufacturing.
